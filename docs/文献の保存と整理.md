# 文献の保存と整理

文献を探す・手に入れる・控える・見つけ直す流れの全体と、Zotero・Google ドライブでの保存の決まり。2026-10-21 に決めた（PDF の保存先は「B：Zotero は無料のまま、PDF は Google ドライブにリンクして置く」）。

## 1. 役割分担

| 段階 | 使うもの | 置くもの・やること |
|---|---|---|
| どこを調べるか | Editorial-Workspace `books/_research_sources/README.md` | 用途別の調査先（NDL の調べ方） |
| 新しい研究を知る | edu-research-watch（定期の収集）、Elicit（問いから英語文献を探す・要点を比べる） | 読みたい論文が見つかったら、DOI を文献ハブへ |
| 1本を手に入れる | 文献ハブ（このリポジトリ） | 無料版・図書館・複写などの入手ルートを見る。台帳は「入手待ち」の短いリストとして使う |
| **控える（正本）** | **Zotero** | 書誌・タグ・メモ・注釈。PC とスマホは Zotero の公式アプリで同期する |
| PDF の置き場 | Google ドライブ `50_Reserch_論文/_Zotero` | Zotero が名前を付けて移す。手で名前を変えたり移したりしない |
| 学習指導要領・中教審 | Google ドライブ `◆学習指導要領` と Editorial-Workspace `books/_policy_intel` | 公的資料の原本 PDF と、検索用の本文 |

文献ハブの同期（GitHub の Gist）は、入手待ちの台帳と設定だけに使う。読んだ文献・残す文献は Zotero に送り、Zotero 側で管理する。

## 2. Zotero の設定（PC で1回）

画面の項目名は Zotero 7 の日本語表示を想定して書いている。実際の名前と違うときは近いものを選ぶ（この手順は実機で未確認）。

1. **Zotero 7 をインストールしてログインする**。設定の「同期」で、データの同期を有効にする。ファイルの同期は Zotero のストレージ（無料は 300MB）を使うので、PDF はそこに入れない（下の 3・4 でドライブに置く）。
2. **基準ディレクトリを決める**：設定 →「詳細」→「ファイルとフォルダ」→ リンク添付ファイルの基準ディレクトリに、Google ドライブの `03_ROUTINE_継続・参照\50_Reserch_論文` を指定する。PC が変わってもリンクが切れにくくなる。
3. **ファイル名の自動変更**：設定 →「一般」→ ファイル名の変更で、親アイテムの情報から名前を付ける。形式は `年_筆頭著者_題名（短く）`。例：`{{ year suffix="_" }}{{ firstCreator suffix="_" }}{{ title truncate="40" }}`。
4. **Attanger（添付ファイルを移すプラグイン）**を入れ、移動先を `50_Reserch_論文\_Zotero` にする。PDF を Zotero に入れると、名前を付けてドライブへ移し、リンクとして残る。
5. **ブラウザ拡張 Zotero Connector** を入れる。論文ページから書誌と PDF を1クリックで取り込める。
6. 文献ハブの設定で Zotero の API キーを入れる（端末ごとに必要。安全のため同期しない）。

スマホ（Zotero のアプリ）では、書誌・メモ・タグは見られるが、ドライブにリンクした PDF は開けない。PDF は Google ドライブのアプリでファイル名を検索して開く。スマホで PDF に注釈したいものだけは、Zotero に直接入れる（300MB の範囲で）。

## 3. 整理の決まり

- **フォルダで分類しない**。分類は Zotero のコレクションとタグで行う。
  - コレクション：用途の大分類（例：`教育研究`、`統計・方法`、`AI・技術`、`産業・企業`、`表記・著作権`）
  - タグ：`案件:NN_書名`（Editorial-Workspace の案件番号）、`主題:…`、`状態:未読`／`状態:読了`
- **ファイル名は Zotero に付けさせる**（`年_筆頭著者_題名.pdf`）。官公庁・企業の資料も Zotero に「報告書」として入れ、著者欄に発行者（例：総務省）を入れれば、同じ形の名前になる。
- 手で保存するしかないものは、`YYYY_発行者_資料名.pdf`、区切りは `_` だけにする。
- **探すときは Zotero で検索する**。PDF の本文も検索できる（設定の「検索」で全文索引が有効になっていること）。

## 4. 週1回の整理（10分）

1. ドライブの `50_Reserch_論文/_inbox` と、ダウンロードフォルダにたまった PDF を Zotero に入れる（ドラッグして、右クリック →「親アイテムを作成」で書誌を取る）。
2. コレクションとタグを付ける。案件で使うものには `案件:NN_…` を付ける。
3. Elicit で見つけたものは、Elicit から RIS で書き出し、Zotero の「ファイル → 読み込み」で取り込む。
4. 文献ハブの台帳で、入手済みになったものを Zotero に送る（「Zotero に送る」）。

## 5. Google ドライブの構成

```
03_ROUTINE_継続・参照/
├── 50_Reserch_論文/
│   ├── _Zotero/      Zotero（Attanger）が管理する PDF。手で触らない
│   ├── _inbox/       取り込み待ち。週1回空にする
│   └── （既存の 10_〜90_ のフォルダ）  Zotero へ取り込み終わったら空になる
└── ◆学習指導要領/
    ├── 10_学習指導要領・解説/   告示年_学校種_本文か解説_教科.pdf（例：2017告示_小学校_解説_算数.pdf）
    ├── 20_中教審・審議会/       YYMMDD_会議名_回/（いまの 26-中教審 の中身）
    ├── 30_報道・解説記事/       YYMMDD_媒体_見出し.pdf
    └── 90_旧版/                 改訂前の学習指導要領・解説（いまの ◆過去の算数編 など）
```

- `50_Reserch_論文/10_MEXT_公的資料` の学習指導要領解説（情報編）などは `◆学習指導要領` へ移す。
- 中教審の資料のうち、企画で基準にするものは Editorial-Workspace の `books/_policy_intel` に検索用の本文を作る（同 README の運用ルール）。

## 6. 既存の資料の移し方

1. 一度に全部はやらない。案件で使う分野（コレクション）ごとに、フォルダの PDF を Zotero にドラッグする。
2. 書誌が自動で取れないもの（官公庁・企業の資料、note の記事など）は、親アイテムを手で作る（種類：報告書・Web ページ）。
3. 重複（同じ PDF の `(1)` 付きなど）は Zotero の「重複アイテム」でまとめる。
4. 中身が分からない名前のファイル（例：`36_31.pdf`、`ja.pdf`）は、開いて書誌を取ってから入れる。
