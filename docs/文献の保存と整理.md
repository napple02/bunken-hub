# 文献の保存と整理

文献を探す・手に入れる・控える・見つけ直す流れの全体と、Zotero・Google ドライブでの保存の決まり。2026-10-21 に決めた（PDF の保存先は「B：Zotero は無料のまま、PDF は Google ドライブにリンクして置く」）。同日、PC で設定を済ませ、ドライブの既存の PDF をすべて Zotero にリンクした（下の 2・6）。

## 1. 役割分担

| 段階 | 使うもの | 置くもの・やること |
|---|---|---|
| どこを調べるか | Editorial-Workspace `books/_research_sources/README.md` | 用途別の調査先（NDL の調べ方） |
| 新しい研究を知る | edu-research-watch（定期の収集）、Elicit（問いから英語文献を探す・要点を比べる） | 読みたい論文が見つかったら、DOI を文献ハブへ |
| 1本を手に入れる | 文献ハブ（このリポジトリ） | 無料版・図書館・複写などの入手ルートを見る。台帳は「入手待ち」の短いリストとして使う |
| **控える（正本）** | **Zotero** | 書誌・タグ・メモ・注釈。PC とスマホは Zotero の公式アプリで同期する |
| PDF の置き場 | Google ドライブ `50_Reserch_論文` の分類フォルダ | Zotero のコレクションと同じ名前・同じ階層のフォルダ。Zotero からはリンクで参照する |
| 学習指導要領・中教審 | Google ドライブ `50_Reserch_論文/10_MEXT_学習指導要領・公的資料` と Editorial-Workspace `books/_policy_intel` | 公的資料の原本 PDF（Zotero にもリンク済み）と、検索用の本文 |

文献ハブの同期（GitHub の Gist）は、入手待ちの台帳と設定だけに使う。読んだ文献・残す文献は Zotero に送り、Zotero 側で管理する。文献ハブから送った論文はライブラリの直下に入るので、Zotero でコレクションへ入れる。

## 2. Zotero の設定（PC で1回。2026-10-21 に実施済み）

1. **Zotero 7 をインストールしてログインする**。設定の「同期」で、データの同期を有効にする。ファイルの同期はオフにする（Zotero のストレージは無料で 300MB。PDF はドライブに置く）。
2. **基準ディレクトリ**：リンク添付ファイルの基準ディレクトリを `マイドライブ\50_Reserch_論文` にする。Zotero には基準からの相対パスで残るので、PC が変わってもリンクが切れにくい。
3. **ファイル名の付け方**：親アイテムがあるファイルの名前の形式を `{{ year suffix="_" }}{{ firstCreator suffix="_" }}{{ title truncate="40" }}`（`年_筆頭著者_題名`）にする。リンクしたファイルを Zotero が勝手に名前を変える設定（リンクファイルの自動リネーム）はオフのまま。
4. **Attanger（添付ファイルを移すプラグイン）**：
   - 保存先（destDir）：`50_Reserch_論文`。サブフォルダの形式は `{{collection}}` のまま。コレクション `10_MEXT_学習指導要領・公的資料/20_中教審・審議会` で取り込むと、ドライブの同じ名前のフォルダへ入る。
   - 取り込み元：`50_Reserch_論文\_inbox`（補助にダウンロードフォルダ）。`Ctrl+I` で一番新しいファイルを選択中のアイテムに添付する。
   - 移動のあと空になったフォルダは消す（autoRemoveEmptyFolder）。
5. **ブラウザ拡張 Zotero Connector** を入れる。論文ページから書誌と PDF を1クリックで取り込める。
6. 文献ハブの設定で Zotero の API キーを入れる（端末ごとに必要。安全のため同期しない）。
7. **親コレクションで下位もまとめて表示**（recursiveCollections）をオンにする。`10_MEXT…` を選ぶと、会議別のコレクションの中身も一覧に出る。

スマホ（Zotero のアプリ）では、書誌・メモ・タグは見られるが、ドライブにリンクした PDF は開けない。PDF は Google ドライブのアプリでファイル名を検索して開く。スマホで PDF に注釈したいものだけは、Zotero に直接入れる（300MB の範囲で）。

コレクションの作成・既存ファイルの一括リンクに使ったスクリプトと手順は Editorial-Workspace `tools/zotero/README.md` にある。

## 3. 整理の決まり

- **ドライブのフォルダ＝Zotero のコレクション**。名前と階層をそろえる（`10_MEXT_学習指導要領・公的資料/20_中教審・審議会/261005_…` まで同じ）。
  - フォルダを新しく作ったら、`tools/zotero/sync_collections.js` を Zotero で実行してコレクションを足す（対応のないコレクションも一覧で分かる）。
  - フォルダ名を変えたり消したりしたときは、Zotero のコレクションも同じように直す（自動ではそろわない）。名前の先頭が `_` のフォルダ（`_inbox`・`_Zotero`）はコレクションにしない。
  - 分類をまたぐ観点はタグで付ける：`案件:NN_書名`（Editorial-Workspace の案件番号）、`主題:…`、`状態:未読`／`状態:読了`
- **ドライブ上のファイルを手で動かさない・名前を変えない**。動かすと Zotero のリンクが切れる。分類を変えたいときは Zotero でコレクションを移し、Attanger の「Move Attachment」でファイルを移す。
- **ファイル名**：
  - 論文・書籍など書誌が取れるもの：Zotero に付けさせる（`年_筆頭著者_題名.pdf`）。
  - 公的資料・会議資料など、親アイテムを作らずファイルだけをリンクするもの：名前は変わらない。下の 5 の命名に従う。
  - 手で保存するしかないものは、`YYYY_発行者_資料名.pdf`、区切りは `_` だけにする。
- **探すときは Zotero で検索する**。PDF の本文も検索できる（全文索引）。

## 4. 週1回の整理（10分）

1. ドライブの `50_Reserch_論文/_inbox` と、ダウンロードフォルダにたまった PDF を Zotero に入れる。入れたいコレクションを選んでから取り込むと、Attanger が同じ名前のフォルダへ移す。論文は右クリック →「親アイテムを作成」で書誌を取る。
2. タグを付ける。案件で使うものには `案件:NN_…` を付ける。
3. Elicit で見つけたものは、Elicit から RIS で書き出し、Zotero の「ファイル → 読み込み」で取り込む。
4. 文献ハブの台帳で、入手済みになったものを Zotero に送る（「Zotero に送る」）。届いたらコレクションへ入れる。
5. ブラウザ（Zotero Connector）から PDF だけを保存したもの（官公庁の PDF など）は、ドライブへ自動では移らない。Attanger は単独の PDF を受け取ると、まず書誌の自動認識を試し、親アイテムができたときだけ移す（認識できない公的資料は Zotero の内部保存に残る）。コレクションに入れてから右クリック →「Attanger」→「Move Attachment」で移す。マイライブラリ直下に残っていないかを週1回見る。
6. ドライブに直接置いたファイル（中教審の配付資料をまとめて落としたときなど）は、Editorial-Workspace `tools/zotero/README.md` の手順で、置いた場所のままリンク登録する。

## 5. Google ドライブの構成

```

├── 50_Reserch_論文/          Zotero の基準ディレクトリ兼 Attanger の保存先
│   ├── _inbox/       取り込み待ち（Attanger の取り込み元）。週1回空にする
│   ├── _Zotero/      旧の保存先。使わない（空。消してよい）
│   ├── 10_MEXT_学習指導要領・公的資料/   公的資料の原本
│   │   ├── 10_学習指導要領・解説/   告示年_学校種_本文か解説_教科.pdf（例：2017告示_小学校_解説_算数_1_第1章～第2章.pdf）
│   │   ├── 20_中教審・審議会/       YYMMDD_会議名_回/（例：261005_中央教育審議会初等中等教育分科会教育課程部会/）
│   │   ├── 30_報道・解説記事/       YYMMDD_媒体_見出し
│   │   ├── 40_その他の公的資料/     YYYY_発行者_資料名.pdf
│   │   └── 90_旧版/                 改訂前の学習指導要領・解説（算数編/ など）
│   ├── 15_Edu_教育研究/ 20_Rules_表記・引用/ 30_Tech_AI/ 40_Sci_基礎研究/ 50_Biz_産業動向/
│   │   60_Humanities_人文系資料/ 70_Toyokan_仕事関係/ 80_Study_勉強用/ 90_その他/

│   └── 261021_Drive整理の記録   整理で変えた名前・場所の一覧（スプレッドシート）
```

- 2026-10-21 に、上の構成へ整理した（名前の変更・移動・重複のゴミ箱への移動。全100件は `261021_Drive整理の記録` にある）。ゴミ箱へ移したのは、同じサイズの重複7件と空になったフォルダ2件（`20-学習指導要領`、`03_ROUTINE_継続・参照/◆学習指導要領`）で、30日以内ならゴミ箱から戻せる。`◆学習指導要領` の中身は `10_MEXT_学習指導要領・公的資料` に統合した（記録の表の「◆学習指導要領/…」は、いまはこの下にある。スプレッドシートの説明欄に追記済み）。
- 中教審の資料のうち、企画で基準にするものは Editorial-Workspace の `books/_policy_intel` に検索用の本文を作る（同 README の運用ルール）。

## 6. 既存の資料の取り込み（2026-10-21 に実施済み）

- ドライブの分類フォルダ 56 個を Zotero のコレクションとして作り、そこにあった PDF・テキスト 470 件を、移動・リネームせずにその場でリンク登録した（親アイテムなし）。Google ドキュメントのショートカット（`.gdoc`）7件・`desktop.ini`・直下のスプレッドシートは対象外。
- 書誌を付けたいものは、Zotero で選んで右クリック →「メタデータの取得」、取れないもの（官公庁・企業の資料、note の記事など）は親アイテムを手で作る（種類：報告書・Web ページ）。親アイテムを作ってもファイル名は変わらない（リンクファイルの自動リネームはオフ）。
- 重複（同じ PDF の `(1)` 付きなど）は Zotero の「重複アイテム」でまとめる。
