# 文献の保存と整理

文献を探す・手に入れる・控える・見つけ直す流れの全体と、Zotero・Google ドライブでの保存の決まり。2026-10-21 に決めた（PDF の保存先は「B：Zotero は無料のまま、PDF は Google ドライブにリンクして置く」）。

## 1. 役割分担

| 段階 | 使うもの | 置くもの・やること |
|---|---|---|
| どこを調べるか | Editorial-Workspace `books/_research_sources/README.md` | 用途別の調査先（NDL の調べ方） |
| 新しい研究を知る | edu-research-watch（定期の収集）、Elicit（問いから英語文献を探す・要点を比べる） | 読みたい論文が見つかったら、DOI を文献ハブへ |
| 1本を手に入れる | 文献ハブ（このリポジトリ） | 無料版・図書館・複写などの入手ルートを見る。台帳は「入手待ち」の短いリストとして使う |
| **控える（正本）** | **Zotero** | 書誌・タグ・メモ・注釈。PC とスマホは Zotero の公式アプリで同期する |
| PDF の置き場 | Google ドライブ `50_Reserch_論文/_Zotero` | Zotero が名前を付けて移す。手で名前を変えたり移したりしない |
| 学習指導要領・中教審 | Google ドライブ `50_Reserch_論文/10_MEXT_学習指導要領・公的資料` と Editorial-Workspace `books/_policy_intel` | 公的資料の原本 PDF と、検索用の本文 |

文献ハブの同期（GitHub の Gist）は、入手待ちの台帳と設定だけに使う。読んだ文献・残す文献は Zotero に送り、Zotero 側で管理する。

## 2. Zotero の設定（PC で1回）

画面の項目名は Zotero 7 の日本語表示を想定して書いている。実際の名前と違うときは近いものを選ぶ（この手順は実機で未確認）。

0. 前提：PC に「Google ドライブ パソコン版」が入っていて、エクスプローラーに `マイドライブ\50_Reserch_論文` が見えること。その中の `_Zotero`・`_inbox` は 2026-10-21 の整理で作成済み。
1. **Zotero 7 をインストールしてログインする**（zotero.org/download）。設定の「同期」で、データの同期を有効にする。ファイルの同期は Zotero のストレージ（無料は 300MB）を使うので、PDF はそこに入れない（下の 4 でドライブに置く）。
2. **基準ディレクトリを決める**：設定 →「詳細」→「ファイルとフォルダ」→ リンク添付ファイルの基準ディレクトリに、`マイドライブ\50_Reserch_論文` を指定する。この設定は「どこを探すか」を決めるだけで、ファイルを移しはしない（移すのは 4 の Attanger）。PC ごとに1回設定すれば、ドライブの場所が PC で違ってもリンクが切れない。
3. **ファイル名の形式**：設定 →「一般」→ ファイル名の形式をカスタマイズで、`{{ year suffix="_" }}{{ firstCreator suffix="_" }}{{ title truncate="40" }}` にする（`年_筆頭著者_題名（短く）`）。Zotero 7 は、リンクしたファイルの名前は自分では変えないので、名前の変更も 4 の Attanger に任せる。
4. **Attanger（添付ファイルを移すプラグイン）**：GitHub の MuiseDestiny/zotero-attanger の Releases から `.xpi` をダウンロードし、Zotero の「ツール」→「プラグイン」→ 歯車 →「ファイルからプラグインをインストール」で入れる（Firefox で開くと Firefox に入ろうとするので、右クリックで保存する）。Zotero を再起動し、設定 →「Attanger」で次のようにする。
   - 添付の種類（Attach Type）：**リンク**（ここが「保存」のままだと Zotero のストレージに入る）
   - 移動先（Destination）：`マイドライブ\50_Reserch_論文\_Zotero`
   - 自動で名前を変える・自動で移す：オン
   - 既にある PDF は、アイテムを選んで右クリック →「添付ファイルの管理」→「添付ファイルを移動」で移す
5. **ブラウザ拡張 Zotero Connector** を入れる（Chrome・Edge の拡張機能ストア）。論文ページから書誌と PDF を1クリックで取り込め、取り込んだ PDF は 4 の設定で `_Zotero` へ移る。
6. **動作の確認**：Connector で論文を1本取り込み、`_Zotero` に `年_筆頭著者_題名.pdf` ができ、Zotero の添付ファイルのアイコンがリンク（鎖の印）になっていれば完了。
7. 文献ハブの設定で Zotero の API キーを入れる（端末ごとに必要。安全のため同期しない）。

Attanger を使う前に、念のため Zotero のデータフォルダ（設定 →「詳細」→「データの保存場所」）をコピーしておく（Attanger のリリースノートの推奨）。

スマホ（Zotero のアプリ）では、書誌・メモ・タグは見られるが、ドライブにリンクした PDF は開けない。PDF は Google ドライブのアプリでファイル名を検索して開く。スマホで PDF に注釈したいものだけは、Zotero に直接入れる（300MB の範囲で）。

## 3. 整理の決まり

- **フォルダで分類しない**。分類は Zotero のコレクションとタグで行う。
  - コレクション：用途の大分類（例：`教育研究`、`統計・方法`、`AI・技術`、`産業・企業`、`表記・著作権`）
  - タグ：`案件:NN_書名`（Editorial-Workspace の案件番号）、`主題:…`、`状態:未読`／`状態:読了`
- **ファイル名は Zotero に付けさせる**（`年_筆頭著者_題名.pdf`）。官公庁・企業の資料も Zotero に「報告書」として入れ、著者欄に発行者（例：総務省）を入れれば、同じ形の名前になる。
- 手で保存するしかないものは、`YYYY_発行者_資料名.pdf`、区切りは `_` だけにする。
- **探すときは Zotero で検索する**。PDF の本文も検索できる（設定の「検索」で全文索引が有効になっていること）。

## 4. 週1回の整理（10分）

1. ドライブの `50_Reserch_論文/_inbox` と、ダウンロードフォルダにたまった PDF を Zotero に入れる（ドラッグして、右クリック →「親アイテムを作成」で書誌を取る）。
2. コレクションとタグを付ける。案件で使うものには `案件:NN_…` を付ける。
3. Elicit で見つけたものは、Elicit から RIS で書き出し、Zotero の「ファイル → 読み込み」で取り込む。
4. 文献ハブの台帳で、入手済みになったものを Zotero に送る（「Zotero に送る」）。

## 5. Google ドライブの構成

```
マイドライブ/
├── 50_Reserch_論文/
│   ├── _Zotero/      Zotero（Attanger）が管理する PDF。手で触らない
│   ├── _inbox/       取り込み待ち。週1回空にする
│   ├── 10_MEXT_学習指導要領・公的資料/   公的資料の原本。Zotero には入れず、ここを正本にする
│   │   ├── 10_学習指導要領・解説/   告示年_学校種_本文か解説_教科.pdf（例：2017告示_小学校_解説_算数_1_第1章～第2章.pdf）
│   │   ├── 20_中教審・審議会/       YYMMDD_会議名_回/（例：261005_中央教育審議会初等中等教育分科会教育課程部会/）
│   │   ├── 30_報道・解説記事/       YYMMDD_媒体_見出し
│   │   ├── 40_その他の公的資料/     YYYY_発行者_資料名.pdf
│   │   └── 90_旧版/                 改訂前の学習指導要領・解説（算数編/ など）
│   ├── 15_Edu_教育研究/ 20_Rules_表記・引用/ 30_Tech_AI/ 40_Sci_基礎研究/ 50_Biz_産業動向/
│   │   60_Humanities_人文系資料/ 70_Toyokan_仕事関係/ 80_Study_勉強用/ 90_その他/

│   └── 261021_Drive整理の記録   整理で変えた名前・場所の一覧（スプレッドシート）
```

- 2026-10-21 に、上の構成へ整理した（名前の変更・移動・重複のゴミ箱への移動。全100件は `261021_Drive整理の記録` にある）。ゴミ箱へ移したのは、同じサイズの重複7件と空になったフォルダ2件（`20-学習指導要領`、`03_ROUTINE_継続・参照/◆学習指導要領`）で、30日以内ならゴミ箱から戻せる。`◆学習指導要領` の中身は `10_MEXT_学習指導要領・公的資料` に統合した（記録の表の「◆学習指導要領/…」は、いまはこの下にある。スプレッドシートの説明欄に追記済み）。
- 中教審の資料のうち、企画で基準にするものは Editorial-Workspace の `books/_policy_intel` に検索用の本文を作る（同 README の運用ルール）。

## 6. 既存の資料の移し方

1. 一度に全部はやらない。案件で使う分野（コレクション）ごとに、フォルダの PDF を Zotero にドラッグする。
2. 書誌が自動で取れないもの（官公庁・企業の資料、note の記事など）は、親アイテムを手で作る（種類：報告書・Web ページ）。
3. 重複（同じ PDF の `(1)` 付きなど）は Zotero の「重複アイテム」でまとめる。
4. 中身が分からない名前のファイルは、開いて書誌を取ってから入れる（2026-10-21 の整理で、分かる範囲の名前は付け直した）。
