    このページについて・使い方

    何をするページか

    論文を「探す」「本文を手に入れる」「控える」までを1画面で済ませるための入口です。検索エンジンや保存場所は作らず、Google Scholar・CiNii・国立国会図書館・Unpaywall などの既存サービスを束ねて、次に何をすればよいかを示します。大学や研究機関に所属していない人が、本文にたどり着くまでの手間を減らすことを一番の目的にしています。

    国会図書館×一部連携NDLサーチの結果を並べ、デジタル化資料に印を付ける。遠隔複写などの手続きへ案内する
    所属がない場合有料ページで止まりやすい同左著者への依頼文、researchmap・ORCID での連絡先探しまで用意する

    探す力そのものは Google Scholar や CiNii のほうが上です。このページは、それらへ一度に問い合わせ、結果を「どうすれば読めるか」の順に並べ直す役割を担います。

    使い方

    1. 調べる：上の欄に DOI・論文ページの URL・タイトルのどれかを入れます。タイトルなら候補が出るので、目当ての論文を選びます。
    2. 入手する：画面上部の帯が入手しやすさを示します。①無料版 → ②横断検索 → ③図書館などの手続き → ④著者に頼む、の順に試してください。
    3. 控える：「台帳に追加」で読みたい論文を記録し、状態（未入手・入手済・読了）・★（重要）・タグ・メモを付けます。台帳は、タグや★で絞り込めます。「引用・保存」タブでは、参考文献の表記・BibTeX・RIS・CSL JSON・Markdown・Obsidian ノートをコピーできます。台帳の全件は、「書き出し・読み込み」から Obsidian ノートの ZIP にして取り出せます。
    4. 広げる：「関連文献」タブで、参照している論文・引用している論文をたどれます。タイトルで検索したときは、「無料版ありのみ」「日本語のみ」で絞り込み、新しい順や被引用の多い順に並べ替えられます。

    論文ページから1クリックで開く

    次のボタンをブックマークバーへドラッグしてください。論文のページでそれを押すと、ページ内の DOI を拾って文献ハブを開きます。

    文献ハブで開く

    アプリとして使う（ホーム画面に追加）

    • Android・パソコンの Chrome / Edge：画面上部の「アプリとして追加」を押すか、ブラウザのメニューから「アプリをインストール」を選びます。
    • iPhone・iPad の Safari：共有ボタン →「ホーム画面に追加」。
    • 追加すると、アドレスバーのない全画面で開きます。画面と台帳はオフラインでも開けます（検索には通信が必要です）。
    • Android では、他のアプリの「共有」から文献ハブを選ぶと、論文ページの DOI をそのまま調べます。

    別の端末へ引き継ぐ

    • 同期（おすすめ）：「設定」→「他の端末と同期」で GitHub のトークン（gist の権限だけ）を入れて「接続して同期」。ほかの端末では、同じトークンを入れるだけで台帳と設定が届きます。以後は変更のたびに自動で合わせます。
    • ファイルで移す：「書き出し・読み込み」で JSON を書き出し、別の端末で「JSON を読み込む」。設定（メールアドレスなど）も一緒に入ります。トークンは含まれません。

    データの扱い

    • 台帳と設定は、このブラウザの中（localStorage）に保存されます。同期を使わない限り、サーバーには送りません。
    • メールアドレスは、Unpaywall・OpenAlex・Crossref への問い合わせにだけ添えます。同期を使う場合は、あなたの GitHub のシークレット Gist にも保存されます。
    • ブラウザのデータを消すと、この端末の台帳は消えます。同期していない場合は、「書き出し・読み込み」の JSON で、ときどき Google ドライブなどへバックアップしてください。

    できないこと

    • Google Scholar には公式の API がないため、画面内には結果を出さず、リンクだけを用意しています。
    • 有料の論文を無料にすることはできません。合法に公開されている版と、正規の入手手段だけを案内します。

    設定

    他の端末と同期 おすすめ

    台帳と設定を、あなたの GitHub アカウントの「シークレット Gist」に預けて、別の端末へ引き継ぎます。別の端末では、同じトークンを入れるだけです。

    しくみと注意
    • 同期するのは、台帳（文献・状態・メモ）と、メールアドレス・名前・保存先フォルダ・引用形式・CiNii appid です。トークンと OpenAlex の API キーは同期しません。
    • シークレット Gist は、検索には出ませんが、URL を知っている人なら誰でも読めます。メールアドレスや台帳の内容が入るので、URL は人に見せないでください。気になる場合は、同期せず、JSON のバックアップで手動で移してください。
    • 2台で同時に編集しても、文献ごとに新しいほうを残して合わせます。同じメモを両方で書き換えたときは、あとから保存したほうが残ります。
    • 接続を解除しても、GitHub 上の Gist は消えません。消すときは GitHub の Gist のページから削除してください。
    Zotero と連携 任意

    論文の書誌を、あなたの Zotero のライブラリへ送ります。PDF の保管・注釈、Word や Google ドキュメントでの引用は Zotero で行えます。

    詳しい設定

    設定はこのブラウザの中にだけ保存されます。
